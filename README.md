# 知命玄学 FateSage

知命玄学 FateSage 是一款面向 macOS 与 Windows 的本地三体系排盘工具，希望用一个清晰、稳定、可复核的桌面界面，同时呈现四柱八字、西洋占星与紫微斗数的结构化命盘。

> 品牌：知命玄学-FateSage  
> 作者：Kee 壳子  
> 招募共同开发者：微信 keekezi

## 项目定位

FateSage 当前专注“准确排盘”，暂不自动生成命理解读。我们优先统一时间、地点和推运口径，让三套体系基于同一份出生资料独立计算，并在同一个界面中相互参照。命理解读能力已经预留接口，将在后续版本独立接入。

## 已实现功能

### 四柱八字

- 自动排出年柱、月柱、日柱和时柱
- 十神、地支藏干、胎元、命宫与身宫
- 起运时间、顺逆排及完整大运区间
- 目标日期对应的流年干支、十神、藏干
- 当前大运识别，以及流年与原局六合、六冲、六害关系

### 西洋星盘

- 太阳、月亮及主要行星黄经
- 上升、下降、天顶、天底与十二宫宫头
- 星体落宫及本命主要相位
- 十二宫宫主星飞宫
- 目标日期行运相位、次限推运与太阳弧推运

当前采用：

- 数据库：Pyswisseph 2.10.3.2 / Swiss Ephemeris
- 黄道体系：回归黄道（Tropical）

### 紫微斗数

- 命宫、身宫、命主、身主与五行局
- 十二宫宫干支、主星、辅星及本命四化
- 大限、流年、小限和目标年份四化飞宫

### 地点与时间

- 中国省、市、县/区三级出生地点选择
- 自动匹配县区经纬度
- 内部使用 Asia/Shanghai 历史时区
- 自动计算真太阳时
- 对中国历史夏令时进行修正，降低临近时辰边界的误盘风险

## 本地运行与隐私

排盘引擎随桌面应用一起封装，排盘过程在本机完成，不需要把姓名、出生日期或出生地点上传到网络。安装完成后，核心排盘功能可离线使用。

## 下载
